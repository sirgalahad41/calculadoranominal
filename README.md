# Calculadora de Nómina Colombiana

Proyecto Android con Jetpack Compose. Implementa el **modelo simplificado del taller de septiembre de 2026**, no una liquidación laboral oficial.

## Abrir en Android Studio
1. Descomprime el ZIP y selecciona **Open** sobre la carpeta `CalculadoraNomina`.
2. Espera la sincronización de Gradle (requiere Internet para descargar dependencias).
3. Selecciona un emulador Android y ejecuta **app**.

## Archivos
- `NominaCalculator.kt`: constantes, reglas y cálculo, sin dependencias de la interfaz.
- `MainActivity.kt`: pantalla Compose, validaciones, campos e interruptores reutilizables.
- `strings.xml`: textos visibles.
- `drawable/rango_*.xml`: tres ilustraciones vectoriales para los rangos.

## Evidencias pendientes
Añade aquí tu nombre completo, código estudiantil, capturas de los casos A-D y una validación E. Agrega la carpeta `evidencias/` con capturas de Dice Roller y Tip Time para la entrega completa.

**Nota:** los casos numéricos A y B del enunciado parecen tener pequeñas diferencias con las fórmulas que él mismo exige. El código prioriza las fórmulas explícitas.
